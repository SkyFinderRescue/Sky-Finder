Track number legend: the numbers on the XCFind map are the pilot’s track points in order. 1 is an older point. Higher numbers are newer points. The highest number is usually the pilot’s most recent visible location.
Important: XCFind’s California page can still show California pilots who are currently flying outside California. A true California-only filter needs access to the live pilot coordinates before display.
For a true California-only v2, the next step is a small backend or feed reader that keeps only latest pilot positions inside California before showing them.
